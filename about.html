关于本站

这是什么

GameUI Ref 是一个游戏界面设计参考图鉴：把分散的游戏 UI 资料整理成可筛选、可检索、可放大细看的静态数据库，帮助游戏界面设计师找参考、比风格、学结构。功能形态参照 GAMEUI.net（游戏 UI 设计师社区）。

怎么用

  • 找风格：在游戏库按国风 / 欧美 / 二次元 / Q版卡通等 7 种风格、平台、类型、年份组合筛选。
  • 看细节：在截图库点击任意截图放大到最高 1080px 宽的原图，方向键 ← → 连续翻看，灯箱里能看到尺寸与标签。
  • 学方法：文章区收录规范搭建、商业化系统设计等方法论，点击前往原文。

图片来源与版权

本站所有游戏界面截图、作品图片与文章数据均采集自 GAMEUI.net（快照日期 2026-10-02），通过其公开图片 CDN 引用，未复制存储任何图片文件。图片与内容版权归原作者、上传者及相关游戏公司所有。本站为个人学习与技术演示用途的非商业静态站点，如需移除内容请联系我们。

截图库当前覆盖 10 款游戏的完整截图集：原神、明日方舟、王者荣耀、哈利波特：魔法觉醒、和平精英、战双帕弥什、天涯明月刀、忘川风华录、阴阳师：百闻牌、斗罗大陆：魂师对决。每张截图的灯箱面板均提供 GAMEUI 源页链接。

设计语言

站点视觉基于「zcode-dark」设计语言构建：#161616 深色底 + oklch 三级面板色阶 + sky-500 单点强调 + amber-500 商业高亮，hairline（白 @8%）分层替代阴影，胶囊主按钮 + 10/16px 圆角卡，60/700 大标题与 Geist 系字体栈。图片为主的图库站点选择暗色底，是为了让界面截图本身成为页面上最亮的存在。

技术

纯静态实现：HTML + 原生 CSS/JS，无框架、无构建步骤。数据以内嵌 JSON 随站点分发（218 KB），筛选、搜索、灯箱全部在浏览器本地完成。
