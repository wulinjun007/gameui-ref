# GameUI Ref · 游戏界面参考图鉴

一个游戏 UI 设计参考图鉴的纯静态站点：把分散的游戏界面资料整理成可筛选、可检索、可放大细看的暗色图鉴数据库。

- **线上**：https://wulinjun007.github.io/gameui-ref/ （GitHub Pages；Netlify 版 gameui-ref.netlify.app 待账户额度恢复后部署，站点已建好 ID `97e406cd-d868-41be-9d94-b7ccd29af727`）
- **功能形态参照**：[GAMEUI.net](https://www.gameui.net/)（游戏 UI 设计师社区）
- **设计语言**：`zcode-dark`（来自 design-system-extraction-2026-10 / 03-zcode 提取）：#161616 底 + oklch 三级面板 + sky-500 单点强调 + amber-500 高亮 + hairline 分层（无阴影）+ 胶囊主按钮 + 60/700 大标题

## 收录规模（快照 2026-10-02）

| 类型 | 数量 | 说明 |
|---|---|---|
| 游戏全案 | 568 | 平台 / 类型 / 风格 / 年份四维筛选 |
| 实机界面截图 | 1200 | 覆盖 10 款热门游戏，灯箱可看原图（≤1080px 宽）与元数据 |
| 原创设计作品 | 120 | 网格 + 灯箱，链回 GAMEUI 源页 |
| 方法论文章 | 63 | 卡片列表，点击前往原文 |

## 功能

- 首页：图片拼贴 hero、统计、热门游戏、风格合辑、截图/作品/文章预览
- 游戏库：左侧四维筛选（带计数）+ 关键词 + 排序 + URL 同步（可分享筛选状态）
- 截图库：按游戏切换 + 瀑布流懒加载 + 灯箱（← → 翻页、尺寸读取、标签、源页链接、`?sid=` 深链）
- 全站导航搜索（游戏/作品/文章分组下拉结果）

## 技术

纯静态 HTML + 原生 CSS/JS，无框架无构建。数据内嵌于 `assets/js/data.js`（约 218 KB），全部交互在浏览器本地完成。图片不经本站存储，直接引用 GAMEUI.net 公开图片 CDN（`img.gameui.net`），并带 1080→720→360 逐级回退。
